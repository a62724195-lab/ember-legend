# ملف تسليم المطوّر (لمحادثة جديدة مع Claude)

اللعبة: «أسطورة الجمر» — HTML5 canvas في ملف واحد. الكود المصدري مقسّم في `dev/src/*.js` ويُجمَّع بـ `dev/build.sh` إلى `out.html`.
النسخة المنشورة: `www/index.html` (ناتج البناء + وسوم head). الإصدار الحالي: 1.7.0.

## قواعد العمل
- الرد بالعربية (لهجة خليجية)، قصير وصادق عمّا اتجرّب بمحاكاة فقط.
- بعد كل تغيير: أعد البناء، حدّث `www/index.html`، ارفع `APP_VERSION` في `dev/src/14t_update.js` و`version.txt` معاً، ثم commit/push، ثم شغّل الـ workflow:
  `gh api -X POST repos/a62724195-lab/ember-legend/actions/workflows/release.yml/dispatches -f ref=main`
- اللعبة للتحميل فقط (Windows/Android) — لا نسخة متصفح ولا GitHub Pages.
- الاختبار: Playwright Chromium على `ember_legend.html?nointro` + مكشوفات `window.__hd` و`__st`.

## ما تم
قصة «جمر الأعماق» (8 مراحل + زعيمان)، البرج اللانهائي (زعيم كل 5 طوابق)، اندفاع + جامور، 4 جمرات خاصة، غرفة المونتاج السرية (مكتبة)، مقدمة سينمائية، تحديث من داخل اللعبة، اهتزاز، وضع تصوير، وضع اليد الواحدة، إعلان داخل اللعبة (`?trailer`).

## المتبقي
نهايات متعددة + مهام جانبية، تحدٍّ يومي، تعريب إنجليزي، إعدادات رسوميات، نقل مفتاح التوقيع إلى GitHub secrets، وسبب رسالة «تعذر التحميل» في التحديث (لم يُحسم).

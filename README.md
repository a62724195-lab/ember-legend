# 🔥 أسطورة الجمر (Ember Legend)

لعبة أكشن وقصة بعالم قلعة الجمر. تشتغل على الجوال (أندرويد وآيفون) وعلى ويندوز، وبدون إنترنت بعد أول فتح.

## كيف تلعبها

| الجهاز | الطريقة |
|---|---|
| **أي جهاز (متصفح)** | افتح رابط اللعبة: `https://اسم-حسابك.github.io/ember-legend/` |
| **أندرويد** | نزّل `Ember-Legend-Android.apk` من صفحة **Releases** وثبّته (فعّل "تثبيت من مصدر غير معروف"). أو افتح الرابط في Chrome ← ⋮ ← **تثبيت التطبيق**. |
| **آيفون** | افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**. |
| **ويندوز** | نزّل `Ember-Legend-Setup-x.x.x.exe` للتثبيت، أو `Ember-Legend-Portable-x.x.x.exe` للتشغيل بدون تثبيت. |

> ويندوز ممكن يظهر تحذير SmartScreen لأن الملف غير موقّع رقمياً. اضغط **مزيد من المعلومات ← تشغيل على أي حال**.

## الرفع على GitHub (مرة وحدة)

1. أنشئ مستودع جديد اسمه `ember-legend` (Public).
2. ارفع كل محتويات هذا المجلد للمستودع (أو بالأوامر):
   ```bash
   git init
   git add .
   git commit -m "Ember Legend 1.0"
   git branch -M main
   git remote add origin https://github.com/اسم-حسابك/ember-legend.git
   git push -u origin main
   ```
3. من المستودع: **Settings ← Pages ← Source: GitHub Actions**. بعد دقيقة يشتغل رابط اللعبة.
4. لبناء ملفات ويندوز وأندرويد:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   انتظر 10 إلى 15 دقيقة (تبع **Actions**)، وتلقى الملفات في **Releases**.
   وتقدر بدل الوسم تشغّلها يدوياً: **Actions ← Build release ← Run workflow** (الملفات تطلع في Artifacts).

## تحديث اللعبة

استبدل `www/index.html` بالنسخة الجديدة وارفعها. الموقع يتحدث تلقائياً. وللملفات الجاهزة (exe وapk) ارفع وسم جديد مثل `v1.0.1` وغيّر رقم `version` في `package.json`.

## ملاحظات

- التقدّم والإعدادات (ومنها مكان أزرار اللمس) تنحفظ داخل الجهاز نفسه ولا تنتقل بين الأجهزة.
- الخطوط تتحمل من الإنترنت أول مرة، وبعدها تُحفظ. بدون إنترنت أول مرة يستخدم الجهاز خطاً بديلاً.
- نسخة الأندرويد موقّعة بمفتاح التطوير (debug)، وتصلح للتثبيت المباشر. لو تبي تنشرها في Google Play لازم توقيع Release خاص بك.
- في ويندوز: **F11** للشاشة الكاملة.

## هيكل المشروع

```
www/            اللعبة نفسها (index.html) + manifest + sw.js + icons
electron/       غلاف ويندوز
build/          أيقونة ويندوز
assets/         أيقونة أندرويد
.github/workflows/  البناء التلقائي (pages.yml, release.yml)
```
